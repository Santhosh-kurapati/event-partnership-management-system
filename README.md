Event Partnership Management System

Developed a comprehensive RESTful API for an event management platform using Spring Boot, enabling organizations to create, manage, and partner on events. Implemented a robust authentication system with role-based access control (ADMIN and PARTNER_REP roles) using Spring Security and JWT tokens. Designed and built a multi-layered architecture with controllers, services, and repositories following best practices.
Key Technical Implementations:

Created secure endpoints with Spring Security and JWT authentication for user registration and login
Implemented role-based authorization with fine-grained access control across all API endpoints
Developed comprehensive CRUD operations with Spring Data JPA for events, partners, and partnership management
Utilized DTOs and MapStruct for efficient object mapping between entity and API layers
Enforced data validation with Jakarta Bean Validation constraints
Applied aspect-oriented programming (AspectJ) for cross-cutting concerns like logging
Designed a global exception handling system for consistent error responses
Simplified development with Lombok for boilerplate code reduction
Followed RESTful design principles with proper HTTP methods and status codes
